# هات‌فیکس ۱ فاز ۸ — اصلاح Build و Migration

این نسخه سه خطای گزارش‌شده را برطرف می‌کند:

- ناسازگاری `Span<byte>.SequenceEqual` هنگام اعتبارسنجی امضای PNG
- وابستگی مستقیم سرویس خرید به ویژگی `SupplierPurchases` روی DbContext
- نمایش ندادن خطای واقعی Build در اسکریپت Migration

## روش نصب پیشنهادی

نسخه را در یک پوشه تازه استخراج کنید و آن را روی فایل‌های نسخه قبلی کپی نکنید؛
این کار از ترکیب شدن فایل‌های قدیمی و جدید جلوگیری می‌کند. سپس از ریشه پروژه اجرا کنید:

```powershell
.\scripts\apply-phase8-migration.ps1
.\scripts\verify-phase7b.ps1
```

اسکریپت Migration اکنون ابتدا پروژه Infrastructure را Restore و Build می‌کند و فقط
پس از Build موفق، Migration را با `--no-build` اجرا می‌کند. بنابراین اگر خطای دیگری
وجود داشته باشد، مسیر فایل و شماره خط مستقیماً در خروجی نمایش داده می‌شود.
