# تحویل فاز ۸: خرید، سود واقعی، نمودار و تصویر محصول

## راه‌اندازی روی دیتابیس فعلی

پس از جایگزینی سورس، PowerShell را در ریشه پروژه باز کنید و فقط یک‌بار اجرا کنید:

```powershell
.\scripts\apply-phase8-migration.ps1
```

این Migration افزایشی است و اطلاعات قبلی را حذف نمی‌کند. سپس بررسی کامل پروژه:

```powershell
.\scripts\verify-phase7b.ps1
```

## گردش کار جدید

1. در «محصولات» محصول و تصویر آن را ثبت کنید و حداقل یک مدل/SKU بسازید.
2. در «انبار» حداقل یک انبار فعال وجود داشته باشد.
3. در «تأمین‌کنندگان و خرید»، روی «ثبت خرید» تأمین‌کننده بزنید.
4. انبار، مدل کالا، تعداد، قیمت خرید واحد و قیمت فروش واحد را وارد کنید.
5. ثبت خرید به‌صورت اتمیک موجودی و میانگین بهای خرید را به‌روز می‌کند و قیمت فروش دستی جدید را فعال می‌کند.
6. بعد از فروش و تأیید پرداخت، قیمت خرید همان لحظه داخل سفارش و فاکتور Snapshot می‌شود.
7. داشبورد، سود واقعی را از اختلاف مبلغ فروش و بهای خرید (پس از تخفیف) محاسبه می‌کند.

## رفتار داده‌های قدیمی

برای موجودی و فاکتورهایی که قبل از فاز ۸ قیمت خرید نداشته‌اند، قیمت خرید صفر فرض نمی‌شود. سود این خطوط تا زمانی که قیمت خرید مستند وجود نداشته باشد از سود واقعی کنار گذاشته می‌شود؛ بنابراین گزارش قبلی به‌طور مصنوعی زیاد نمی‌شود.

## تصویر محصول

فرمت‌های JPG، PNG و WebP تا ۵ مگابایت پذیرفته می‌شوند. فایل‌ها در حالت پیش‌فرض داخل مسیر محلی زیر و خارج از دیتابیس ذخیره می‌شوند:

```text
%LOCALAPPDATA%\VendomeJewelry\ProductImages
```

متادیتا و دسترسی تصویر در API احراز هویت می‌شود. تصویر موجود را می‌توان از کارت محصول با «تغییر تصویر» جایگزین کرد.
