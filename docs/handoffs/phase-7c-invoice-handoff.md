# راهنمای تست گردش فاکتور Phase 7C-A

## قبل از اجرا

در PowerShell و در ریشه Solution اجرا کن:

```powershell
.\scripts\verify-phase7b.ps1
```

این نسخه Migration جدید ندارد. اگر Migration بخش‌های عملیاتی Phase 7B قبلاً
اعمال شده است، دوباره تغییری در دیتابیس لازم نیست.

سپس در Visual Studio این سه پروژه را هم‌زمان اجرا کن:

1. `GoldInvoice.Api`
2. `GoldInvoice.Worker`
3. `VendomeJewleryDesktopApp`

## تست اصلی

1. از `مشتریان` یک مشتری دارای شماره تلفن و نشانی انتخاب کن.
2. `ثبت سفارش` را بزن و سفارش را کامل کن.
3. از `سفارش‌ها` روی `ثبت پرداخت` بزن.
4. روش پرداخت و شماره پیگیری را ثبت کن.
5. پس از موفقیت پرداخت، برنامه باید خودکار صفحه `فاکتورها` و پیش‌نمایش همان
   فاکتور را باز کند.

## تست چهار عملیات فاکتور

- آیکون چشم: پیش‌نمایش A4 فاکتور را باز می‌کند.
- آیکون مداد: فقط نام/شناسه مشتری و اطلاعات تماس/نشانی چاپی را با دلیل اصلاح
  می‌کند. مبلغ، اقلام و شماره فاکتور نباید قابل ویرایش باشند.
- آیکون دانلود: پنجره Windows برای ذخیره فایل PDF را باز می‌کند. فایل را ذخیره
  و دوباره باز کن؛ متن فارسی، جدول و جمع نهایی باید خوانا باشند.
- آیکون چاپ: تعداد نسخه و دلیل را می‌گیرد، پیش‌نمایش را نشان می‌دهد و مستقیم
  به چاپگر پیش‌فرض Windows می‌فرستد. قبل از تست، چاپگر موردنظر را در Windows
  به‌عنوان Default تنظیم کن.

## نتیجه مورد انتظار

- فاکتور فقط بعد از پرداخت تأییدشده صادر و قابل چاپ باشد.
- فاکتور باطل‌شده قابل اصلاح یا چاپ نباشد.
- دانلود PDF نیاز به پرینتر نداشته باشد.
- چاپ ناموفق پیام روشن بدهد و تلاش آن در سابقه چاپ باقی بماند.
- چاپ دوم به‌عنوان چاپ مجدد ثبت شود و دلیل داشته باشد.
- هیچ‌یک از اجرت، مالیات یا هزینه ساخت در PDF نمایش داده نشود.

## قالب نهایی

قالب A4 فعلی موقت و قابل‌استفاده است. بعد از ارسال نمونه PDF تأییدشده، ظاهر و
مختصات فیلدها در مرز واحد قالب جایگزین می‌شوند و گردش سفارش، پرداخت، ویرایش،
دانلود و چاپ تغییر نمی‌کند.
